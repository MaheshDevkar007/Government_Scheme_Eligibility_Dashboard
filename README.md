# Government Scheme Eligibility Dashboard

#  Project Overview
This project is an interactive Power BI dashboard that analyzes Indian Government Scheme Eligibility data. It provides insights into applicants, schemes, age groups, categories, income, and state-wise distribution.

#  Dashboard Features
- Total Schemes
- Total Applicants
- Average Age
- Average Income
- State-wise Applicants
- Applicants by Scheme
- Applicants by Age Group
- Applicants by Category
- Interactive State Slicer

#  Tools Used
- Power BI Desktop
- Microsoft Excel / CSV
- Data Visualization
- DAX (Basic)
- GitHub

- Uttar Pradesh has the highest applicant count.
- The dashboard allows interactive filtering using the State slicer.
- Age group and category distribution are visualized for better analysis.
